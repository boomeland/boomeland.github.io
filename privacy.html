Privacy Policy

Sound of Valais Studio · Last updated 10 November 2026

Who we are

Sound of Valais is an independent YouTube channel of ambient sounds, run by its owner from the Valais, Switzerland. Sound of Valais Studio is the private tool the owner uses to publish the channel's own videos. It is not a public service: only the channel owner signs in to it.

YouTube API Services

Sound of Valais Studio uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool accesses

When the channel owner connects the tool, Google asks for permission to manage the owner's YouTube account (scope https://www.googleapis.com/auth/youtube). The tool uses this permission only on the Sound of Valais channel, to:

  • upload the channel's own videos and Shorts, and schedule their publication time;
  • set their title, description, tags, thumbnail and audience settings, including the altered or synthetic content label;
  • create the channel's playlists and add the uploaded videos to them;
  • read the channel name, to confirm which channel is connected.

It does not read comments, subscribers, analytics, messages or any data about other YouTube users.

How data is stored

The authorization token that Google returns is stored only on the channel owner's own computer, in a file that only the tool reads. Temporary access tokens are kept in memory for at most one hour. Video files and their texts never leave the owner's computer except to be sent to YouTube. No other server is involved.

Sharing

No data obtained through Google or YouTube is sold, shared with or transferred to anyone, used for advertising, or used to train AI models. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from the Google Account permissions page, or through the Google security settings. When access is revoked, or on request, the stored token is deleted within 30 days, and in practice immediately. Videos already published stay on YouTube, where they can be managed or deleted in YouTube Studio.

This website

This website uses no cookies, analytics or trackers. Fonts are loaded from Google Fonts.

Contact

For any question about this policy or to request deletion of data: soundofvalais@gmail.com.
